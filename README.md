# 🤖 Airdrop Hunter

Мультивалютный бот-охотник за аирдропами. Автоматически сканирует рынок, находит перспективные проекты, выполняет задания (свапы, бриджи, квесты) и управляет несколькими кошельками.

## 🎯 Что делает

- **Сканер** — находит аирдропы через Zealy, Galxe, Layer3
- **Исполнитель** — автоматически выполняет задания через Playwright
- **Менеджер кошельков** — управляет несколькими аккаунтами
- **Уведомления** — присылает отчёты в Telegram

## 🛠 Технологии

| Стек | Назначение |
|---|---|
| **Python 3.11+** | Язык |
| **web3.py** | Работа с блокчейном |
| **Playwright** | Автоматизация браузера |
| **SQLAlchemy** | База данных |
| **APScheduler** | Планировщик задач |
| **loguru** | Логирование |
| **pydantic** | Валидация данных |

## 📁 Структура

**src/core/** — ядро (config, logger, database)

**src/modules/scanner/** — поиск аирдропов

**src/modules/executor/** — выполнение задач

**src/modules/wallets/** — управление кошельками

**src/services/** — интеграции (Zealy, Galxe, Layer3)

**src/main.py** — точка входа

**data/** — БД и логи

**sessions/** — сессии браузера

**venv/** — виртуальное окружение

## 🚀 Установка

### Шаг 1. Клонировать репозиторий

Команда:
git clone https://github.com/akhmedovr/airdrop-hunter.git

Затем перейти в папку:
cd airdrop-hunter

### Шаг 2. Создать виртуальное окружение

Команда:
python3 -m venv venv

Активировать:
source venv/bin/activate

### Шаг 3. Установить зависимости

Команда:
pip install -r requirements.txt

Затем установить браузер:
playwright install chromium

И системные зависимости:
playwright install-deps chromium

### Шаг 4. Настроить окружение

Скопировать шаблон:
cp .env.example .env

Открыть для редактирования:
nano .env

### Шаг 5. Запустить бота

Команда:
python -m src.main

## ⚠️ Важно

- **.env** не коммитится в git — там секреты
- Приватные ключи кошельков хранятся только в .env
- Используй отдельные кошельки для тестов и реальных денег
- Не заводи больше денег, чем готов потерять
